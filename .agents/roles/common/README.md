# 角色目录说明

本目录用于定义“专家角色”的源文件。

当前阶段先保持最小 MVP，只放 3 个执行专家 + 1 个编排模板：

- `requirement-analyst.md`
- `frontend-implementer.md`
- `code-guardian.md`
- `task-orchestrator.md`

原则：

- 角色文件描述职责与交接，不直接替代 `skills`
- 角色负责“谁来做、做什么、交给谁”
- `skills` 负责“具体怎么做”
- `task-orchestrator` 负责流程路由和专家调度，不承担具体交付实现

后续如需扩展，再按相同结构新增角色文件即可，不需要推翻目录。
