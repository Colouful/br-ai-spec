## 推荐阅读路径

### 路径一：普通开发者

按这个顺序阅读：

1. [开发最佳实践指南](./开发最佳实践指南.md)
2. [5 分钟快速上手](../quick-start.md)
3. [安装指南](../install-guide.md)

适合第一次接触这套方法、希望先完成一次真实需求交付的开发人员。

### 路径二：维护者 / 评审 / 技术讨论

按这个顺序阅读：

1. [架构设计与治理说明](./架构设计与治理说明.md)
2. [OpenSpec / 协议流说明](../openspec-guide.md)
3. [项目介绍与运行机制说明](../paser_three/项目介绍与运行机制说明.md)

适合需要理解协议链路、运行状态、故障定位和后续治理规划的维护者与评审人员。
